# Archive

`XmbWave_original.kt.txt` is the original XMB wave (four white ribbons and one red, AGSL shader, drawn at 30 fps) exactly as it
was in v1.5 (`207a846`). It is also tagged in git as `xmb-wave-original`; to get it back:

    git show xmb-wave-original:app/src/main/java/com/minimaui/app/ui/components/XmbWave.kt

The `.txt` extension keeps it out of the build.

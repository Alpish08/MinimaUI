# Feedback

MinimaUI is a personal project, so I don't accept code contributions or pull requests, and I don't take on co-developers. Feedback is very welcome though:

* **Bugs and ideas**: open an [issue](../../issues). Say which handheld, which emulator and which MinimaUI version you use.
* **Emulators or platforms you want supported**: tell me the emulator's name and the platform. I add them myself.

If an idea of yours ends up in MinimaUI, I'll credit you in the README.

The source is public so you can see what the app does (it is not open source: see [LICENSE](LICENSE)).
